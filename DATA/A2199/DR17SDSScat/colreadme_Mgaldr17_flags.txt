s3_clean          INTEGER: Clean photometry flag (1=clean, 0=unclean)
s3_survey         STRING : Survey  name (e.g. sdss, boss, segue1, segue2, NN, MMT, FLWO_JS, FLWO_KR, FLWO_MG). NN means that redshift information comes from the literature (i.e. NED).
s3_programname    STRING : Program name (e.g. boss, lowz_lrg, southern, segpointed, NN)  
s3_sourceType     STRING : For Legacy, SEGUE-2 and BOSS science targets, type of object targeted as (e.g. NONLEGACY, LRG, QSO, STAR, GALAXY, NN)
s3_zWarning       INTEGER: Bitmask of warning values; 0 means all is well
s3_instrument     STRING : Instrument that this spectrum was observed with (SDSS or BOSS)
s3_BOSS_TARGET1   STRING : BOSS survey primary target selection flags (NN, GAL_LOZ, GAL_CMASS)
