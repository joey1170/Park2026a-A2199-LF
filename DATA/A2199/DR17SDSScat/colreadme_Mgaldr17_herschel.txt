# Herschel DATA
s3_hid     STRING : Herschel Name
s3_hsource STRING : Herschel data source (HeViCS, HRS, HATLAS)
s3_hf100   FLOAT  : 100um flux density in unit of Jy
s3_hf100e  FLOAT  : 100um flux density error in unit of Jy
s3_hf160   FLOAT  : 160um flux density in unit of Jy
s3_hf160e  FLOAT  : 160um flux density error in unit of Jy
s3_hf250   FLOAT  : 250um flux density in unit of Jy
s3_hf250e  FLOAT  : 250um flux density error in unit of Jy
s3_hf350   FLOAT  : 350um flux density in unit of Jy
s3_hf350e  FLOAT  : 350um flux density error in unit of Jy
s3_hf500   FLOAT  : 500um flux density in unit of Jy
s3_hf500e  FLOAT  : 500um flux density error in unit of Jy
