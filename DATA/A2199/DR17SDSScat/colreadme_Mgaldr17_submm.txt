# Ground-based Submm DATA
s3_hid        STRING : Source Name
s3_hsource    STRING : Submm data source (Hwang13, Lee16, Wilson08, Dunne00)
s3_subf350jy  FLOAT  : CSO 350um flux density in unit of Jy
s3_subf350jye FLOAT  : CSO 350um flux density error in unit of Jy
s3_subf450jy  FLOAT  : JCMT 450um flux density in unit of Jy
s3_subf450jye FLOAT  : JCMT 450um flux density error in unit of Jy
s3_subf850jy  FLOAT  : JCMT 850um flux density in unit of Jy
s3_subf850jye FLOAT  : JCMT 850um flux density error in unit of Jy
s3_subf880jy  FLOAT  : SMA 880um flux density in unit of Jy
s3_subf880jye FLOAT  : SMA 880um flux density error in unit of Jy
